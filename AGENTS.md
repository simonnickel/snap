## Repository

- `code-reference/` is a reference library of recurring patterns: self-contained examples to look up when writing similar code.
- `package-template/` holds the files copied into a new package. Its placeholders and `TODO` comments are intentional and are resolved in the new package.
- `## Packages` in `README.md` describes the packages of `docs/suite/packages-overview.md`. The first sentence of each entry states the same purpose as the package's row in the overview. Further sentences can add detail.
