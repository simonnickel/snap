# Writing Style

Conventions for all written content: documentation, code comments, AGENTS.md, README, skills and similar.

## Language

- Use American English.
- No Oxford comma.
- Avoid semicolons and mid-sentence dashes. Consider a new sentence, conjunction, colon, comma, parentheses or rewording instead.
- Describe behavior in present tense: "Returns the cached value", not "Will return the cached value".

## Structure

- When presenting multiple points, use a list rather than prose.
- In a list, prefer splitting into two bullets over joining two items with punctuation.
- Keep bullet style consistent within a list or section: all full sentences or all fragments.

## Clarity

- Avoid phrasing that is open to misinterpretation.
- Cut vague qualifiers ("generally", "typically", "in most cases") or state the actual condition.
- Refer to code symbols by their exact identifier, not a paraphrase.
