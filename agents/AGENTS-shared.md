# The SNAP Suite

SNAP (SN App Packages) is a set of Swift libraries for building iOS apps. `snap/` is the coordinating repository. The packages live alongside it as individual git repositories.

## Documentation

Any documentation about the suite lives in `snap/docs/`.

## Agent Setup

- `snap/docs/agent-setup.md` describes how the agent configuration is structured and loaded.
- After changing a skill in `snap/agents/skills/`, run `snap/agents/setup.sh` to copy it into the skill folders of each agent tool.
