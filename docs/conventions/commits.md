# Commits

- A commit covers one change. Unrelated changes go into separate commits.
- The message describes the end state of the diff, not the steps that led to it.

## Headline

- Uses imperative mood.
- Stays under 72 characters.
- Describes the goal, not the operation.

## Body

- Explains the motivation: the problem, constraints or tradeoffs.
- Does not restate what the diff shows.
- Is left out when the headline is enough.
- Uses a list for several points.
