# Formatting

Applies to Swift source files.

## Code Structure

- Structure a file with `// MARK: - XYZ` so its sections are findable in the minimap.
- Structure a block like a text. Related lines stay together, separated from other blocks by an empty line.

## Multi-line indentation

Use Xcode default formatting with `control + m`.

## Trailing commas

- Multi-line parameter and argument lists keep a trailing comma on the last entry.
- Applies to function signatures and call sites.
- Single-line lists have no trailing comma.
